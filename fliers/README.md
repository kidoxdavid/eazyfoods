# eazyfoods fliers

One-page value proposition fliers for printing or saving as PDF. Use them at events, in-store, or for partner outreach.

## Contents

| File | Audience |
|------|----------|
| `chef-value-proposition` | Chefs – join the platform, list cuisines, get orders |
| `vendor-value-proposition` | Vendors – sell groceries, manage store, products, and orders |
| `driver-value-proposition` | Delivery drivers – sign up, flexible hours, earn per delivery |
| `customer-value-proposition` | Shoppers – why shop eazyfoods (groceries + chef meals) |

Each flier has an **HTML** version (print-friendly, open in browser) and a **Markdown** version (for email or docs).

## How to save as PDF

1. Open the `.html` file in your browser (Chrome, Safari, or Edge).
2. **File → Print** (or Ctrl/Cmd + P).
3. Choose **Save as PDF** or **Print to PDF** as the destination.
4. Print. The “Save as PDF” note at the top is hidden when printing.
